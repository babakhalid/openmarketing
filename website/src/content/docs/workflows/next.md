`/next <slug>` is the returning founder's shortcut. It reads the context, latest diagnosis, active strategy and plan, and recent reports instead of restarting discovery.

The action is selected using impact, evidence strength, user control, effort, reversibility, and prerequisite readiness. The output includes why now, inputs, owner, scope, definition of done, expected learning, decision unlocked, and approval needs.

It deliberately does not return a large backlog. At most two alternatives are allowed, each with the exact condition that would move it ahead of the primary action.

## Output

`outputs/campaigns/<slug>-next.md`.
